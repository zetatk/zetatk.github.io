# ZetaTK Company Homepage

The official homepage and landing page for **ZetaTK**, designed to showcase our services, core expertise, and company vision. This repository hosts the modern, responsive frontend code deployed via GitHub Pages.

🌐 **Live Demo:** [zetatk.org](https://zetatk.org)

---

## 🚀 Features

- **Responsive Design:** Optimized for seamless viewing across smartphones, tablets, and desktops.
- **Modern UI/UX:** Clean aesthetics with smooth animations and layout transitions.
- **Performance Focused:** Minimal external dependencies for lightning-fast loading speeds.
- **SEO Optimized:** Meta tags and semantic structure built to maximize search visibility.
- **Interactive Elements:** Easy-to-use contact forms and dynamic navigation.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)
- **Icons & Fonts:** FontAwesome / Google Fonts (Modify as applicable)
- **Deployment:** GitHub Pages
